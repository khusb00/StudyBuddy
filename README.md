# StudyBuddy
A personal study tracker web application with a toggleable theme feature.

# Features
- Theme Toggle: Switch between dark and light modes with a moon icon that changes accordingly.
- Hero Section: A visually appealing section with transitions and effects.
- Primary Button: Styled buttons with hover effects.

# Technologies Used
- HTML: Defines the structure and content, including div classes and theme toggle buttons.
- CSS: Styles the layout, typography, and visual design, including:
    - Header styles
    - Logo and logo span styles
    - Theme toggle effects
    - Icon effects
    - Login button styles
    - Hero section styles and transitions
    - Primary button styles and hover effects

# Design Highlights
- Interactive Theme Toggle: Seamlessly switch between dark and light modes.
- Visually Appealing Hero Section: Engaging transitions and effects enhance the user experience.

# Notes
- Frontend Focus: This project focuses on the frontend design and user experience.
- Static Design: The project uses HTML and CSS to create a static design.
